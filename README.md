# Gerenciador de Pacientes Odontológicos

## Acesse o projeto

[Demo online](https://gerenciador-pacientes-odontologicos.onrender.com)

## Sobre o projeto

Este projeto consiste em um sistema web simples para gerenciamento de pacientes e registro de procedimentos odontológicos.

A aplicação permite cadastrar o nome do paciente e o procedimento realizado, além de consultar os registros cadastrados.

O projeto foi desenvolvido como uma aplicação prática para estudo de desenvolvimento web e integração entre uma interface e um servidor.

## Funcionalidades

- Cadastro de pacientes
- Registro de procedimentos realizados
- Consulta dos pacientes cadastrados
- Comunicação entre a interface e o servidor por meio de uma API

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript
- Node.js
- Express

## Como executar

1. Instale o [Node.js](https://nodejs.org/).
2. Abra o terminal.
3. Clone o repositório com:
   `git clone https://github.com/peedrovinicius/gerenciador-pacientes-odontologicos.git`
4. Entre na pasta do projeto:
   `cd gerenciador-pacientes-odontologicos`
5. Instale as dependências:
   `npm install`
6. Inicie o servidor:
   `node server.js`
7. Abra no navegador o endereço indicado pelo servidor.

## Estrutura do projeto

O projeto possui uma interface localizada na pasta `public` e um servidor desenvolvido em Node.js no arquivo `server.js`.

Os dados são armazenados temporariamente em memória durante a execução da aplicação.

## Objetivo

O objetivo deste projeto foi desenvolver uma aplicação web funcional, praticando conceitos de desenvolvimento de interfaces, criação de rotas de API e comunicação entre frontend e backend.
